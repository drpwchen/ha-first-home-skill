# 自測情境

四個虛構的新手人物，各由一個沒看過其他情境的 agent 只讀 skill 本體照流程走一遍；每份檔案最後的
`## 執行者筆記` 是執行者自己回報的卡點，`## 評語` 是評分者的評語與據此對 skill 做的修改。

| 情境 | 第一輪（skill 初版） | 第二輪（依第一輪評語修改後重跑） |
|---|---|---|
| 台北租屋小家庭（夫妻＋小孩＋貓，房東不准改線路） | [01](01-taipei-rental-family.md) | [01-r2](01-taipei-rental-family-r2.md) |
| 鄉下透天、長輩同住（子女遠端照顧） | [02](02-rural-house-elders.md) | [02-r2](02-rural-house-elders-r2.md) |
| 常出國單身、剛交屋裝潢中、想要中文語音 | [03](03-frequent-traveler-single.md) | [03-r2](03-frequent-traveler-single-r2.md) |

第二輪之後又依第二輪評語改了一次 skill（瓦斯等安全類可進必買、基礎設施不計入項數、〈規劃理由〉段、
心跳接收器選法），這次的修改**沒有再重跑**。

情境 4 是第三輪盲測（2026-10-21，跑在上述修改之後）：新北自有公寓、已有一堆陸版米家、白天狗獨自在家，
測「已有雲端設備」與「執行端只有雲端家電」。依它的執行者筆記又改了一次 skill（米家本地整合、主機藍牙、
寵物算安全類、已有設備的標法、Google 語音成本），這次的修改**沒有再重跑**。見 [04](04-newtaipei-mijia-owners.md)。

`python scripts/check_skill.py` 會檢查每份情境都有必要段落。
